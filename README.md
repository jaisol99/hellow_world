1. Create Account	Go to GitHub.com and sign up.	You need a personal account to use GitHub.
2. Create Repository	Click + > New repository. Name it hello-world, add a description, select Public, and tick Add a README file.	A repository (or “repo”) is like a project folder that stores all your files and their history.
3. Create a Branch	Inside your new repo, click the main branch dropdown, type readme-edits, and click Create branch.	Branching lets you work on separate copies of the code without affecting the main project.
4. Edit & Commit	On your new branch, click the README.md file, then click the pencil icon (✏️) to edit. Add some text, write a brief commit message, and click Commit changes.	A commit is a saved snapshot of your changes with a message describing what you did.
5. Open a Pull Request	Go to the Pull requests tab and click New pull request. Set readme-edits to compare with main, then Create pull request.	A pull request (PR) proposes your changes and asks to merge them into the main branch.
6. Merge Your Pull Request	In your open PR, click Merge pull request, then Confirm merge. You can also safely Delete branch afterwards.	Merging integrates you
